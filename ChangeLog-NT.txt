o Update 4 (2026.09.23)
This is the biggest update that Rufus-NT will EVER receive, and the compatibility part is finally over. Windows NT 3.51 doesn't have any real USB support, and Win9x would require a complete project rewrite. This will become the base for any future updates.
  - Implemented Windows NT 4.0 support
  - Implemented "LastDiskPhase" and "LastDiskFunction" on NT 4.0 in Rufus-NT registry in case of crashes, as NT4's USB stack can be pretty... fragile
  - Implemented a pop-up dialog for Windows XP systems trying to format exFAT without KB955704 installed, offering to download it from archive.org for the detected system locale
  - Re-enabled the use of external dbx files (previously the internal ones were forced)
  - Moved the registry location from HKCU\Software\Akeo Consulting\Rufus to HKCU\Software\Rufus-NT
  - Reworked the 'About Rufus' dialog to accomodate for the Tahoe font and lower resolutions
  - autorun .inf / .ico creation has been disabled by default
